# OLGP-code
the python implementation of information network skeleton mining algorithm
 We propose a strategy based on On-Line Graph Processing to quickly narrow down the search scope by efficiently partially materializing the information network data cube. Using this approach, we have further developed a highly efficient algorithm that automatically discovers significant substructures within subspaces at any level of multi-dimensional configurations. We explored significant substructures by drilling down from the top layer to the bottom layer of the data cube. Additionally, we designed a significant paths discovery algorithm that calculates the weight of significant paths between these structures based on the theory of maximum flow.
 The work focuses on efficiently and automatically extracting significant structures from large-scale, multi-diemensional and multi-perspective information networks. We evaluated our approach using node and edge pruning strategies on datasets from Stanford's website.
 The main programme constitutes of four parts. First, we create the tables for the upcoming process. Second, preprocess the datasets and inserts the key information into database. Third, construct the graph cube and complete the process of rolling up and drilling down operations. Fourth, discover the significant subspace from different dimensions of the graph cube and value the mining results.
 Attention that Mysql relational database is needed and connected to Python programm.

The above figure is the overall process of our algorithm.First, based on the information network data cube, roll up the original information network to the top-level cube and mine significant substructures in the rolled-up top-level cube network. Since the mined significant substructures need to be connected to each other, the significant paths between them also need to be discovered. At the same time, record the nodes of candidate significant structures during the process. When drilling down, utilize these nodes to detect lower-level network cubes. In the subgraph of the lower-level network cube, repeat the above steps to mine significant substructures and record the nodes in candidate significant structures. Repeat this process until no significant substructures can be discovered or the drill-down reaches the bottom-level cube. 
During the mining process in each level of the data cube, clique graph construction algorithm needs to be executed. Firstly, we mine all maximal cliques from the original information network graph G, ensuring that each node v in these maximal cliques has a degree of at least k which ensures the closeness of the significant structure. These maximal cliques constitute the local candidate significant substructures clk(G). We construct a hyper node for each significant structure to form a new graph. Afterwards, we repeat above process, continuing mining significant structures based on the new graph until no more clique can be mined from the graph. For each clk, we construct a new node in the Clique graph that corresponds to the hyper node formed by the maximal clique. In other words, each node in the Clique graph represents a new node generalized from the mined maximal clique in graph G.  The overall process is shown in the following picture.

In each iteration, we calculate the weight of nodes which represent maximal cliques using maximal flow theory to ensure the integrity of mining results. The process follows the idea of Ford-folkerson algorithm which is implemented in graph subspace mining.py,overall process.py,significant strucutre discovery.py. The main idea is to recursively update the maximal flow between significant structures in residual networks.
